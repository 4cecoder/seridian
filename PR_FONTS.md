# feat(fonts): custom font system — Space Grotesk + Inter + JetBrains Mono

## Summary
Introduces a performant, brand-aligned 3-font system using `next/font/google` with `variable` + `display: swap`, `preload`, Tailwind v4 `@theme inline` wiring, and zero-CLS safeguards. Preserves Seridian cyan/slate palette and stays compatible with Astryx token conventions (`--font-sans` / `--font-heading` / `--font-mono`).

---

## Font Choices

| Role | Font | Var | Weights | Rationale |
|------|------|-----|---------|-----------|
| **Display / Heading** | **Space Grotesk** | `--font-display` | 400,500,600,700 | Modern geometric grotesk; pairs with cyan tech brand, slightly condensed for tight headings, excellent legibility at large sizes. Alternative considered: Syne (more editorial) — Space Grotesk better matches Seridian's engineering tone and `tracking-tight` headings. |
| **Body / UI** | **Inter** (kept) | `--font-body` → maps to `--font-sans` | default (auto, 400-700 via Next) | Proven UI/body font, already in repo, minimal CLS vs. adding Instrument Sans/Sora. Keeping Inter avoids extra payload; Inter 4.x has superior hinting and Tailwind metric compatibility. |
| **Mono / Code / Tech tags** | **JetBrains Mono** | `--font-mono` | 400,500,700 | Astryx `theme-stone` already uses JetBrains Mono for `--font-family-code`; maintains ui-kit parity, ideal for tech tags (`AWS`, `Terraform`), category labels, and step numbers. |

**Budget:** 3 families max, `latin` subset only, selective weights — avoids layout shift from over-fetching. No Instrument Sans / Sora added to keep First Load JS ~103 kB (verify `next build`).

## Performance

- **`display: "swap"`** on all 3 fonts — text visible immediately with system fallback, then swaps without FOIT. Lighthouse-friendly (FID/LCP).
- **`preload: true`** (default for next/font when used in `layout.tsx`) — critical fonts preloaded via `<link rel="preload">` generated by Next. `Inter` (body) and `Space Grotesk` are above-the-fold; JetBrains Mono is below-fold but still preloaded for CLS stability.
- **`subsets: ["latin"]`** only — reduces woff2 payload.
- **`weight` pinning** — Space Grotesk 400-700, JetBrains 400/500/700 (no italic, no thin/black).
- **CLS prevention:**
  - `next/font/google` auto-generates `size-adjust` / `ascent-override` fallback metrics (automatic `@font-face` fallback) — no manual `@font-face` needed.
  - Added `font-synthesis: none` + `text-rendering: optimizeLegibility` + `-webkit-font-smoothing` on `html`/`body`.
  - Fixed Tailwind grid sizes (`64px`), no web-font-induced layout shift.
  - Body keeps `min-h-screen antialiased` placement unchanged.

## Tailwind Wiring

**`src/app/globals.css`**
```css
@import "tailwindcss";

@theme { /* Seridian palette kept */ }

@theme inline {
  --font-sans: var(--font-body);       /* font-sans utility → Inter */
  --font-display: var(--font-display); /* font-display → Space Grotesk */
  --font-mono: var(--font-mono);       /* font-mono → JetBrains Mono */
  --font-heading: var(--font-display); /* Astryx compat: --font-heading alias */
}

html { font-synthesis: none; text-rendering: optimizeLegibility; }
body { font-family: var(--font-sans); }
h1,h2,h3 { font-family: var(--font-display); }
```
- `@theme inline` turns `--font-*` into utilities: `font-sans`, `font-display`, `font-mono` — no extra CSS.
- Preserves `--font-heading` token used by Astryx ui-kit (`Figtree`/`Montserrat` in neutral/stone) — Seridian maps it to display for drop-in compatibility if ui-kit components are imported.

**`src/app/layout.tsx`**
```ts
import { Inter, Space_Grotesk, JetBrains_Mono } from "next/font/google";

const spaceGrotesk = Space_Grotesk({ subsets: ["latin"], variable: "--font-display", display: "swap", preload: true, weight: ["400","500","600","700"] });
const inter = Inter({ subsets: ["latin"], variable: "--font-body", display: "swap", preload: true });
const jetbrainsMono = JetBrains_Mono({ subsets: ["latin"], variable: "--font-mono", display: "swap", preload: true, weight: ["400","500","700"] });

<html lang="en" className={`${spaceGrotesk.variable} ${inter.variable} ${jetbrainsMono.variable} antialiased`}>
```
All 3 variables are set on `<html>` — available globally and inherited, no CLS from late injection.

## Before / After

**Before:**
- Single font: `Inter` via `variable: "--font-inter"` on `<html className={inter.variable}>`
- `globals.css`: `--font-sans: "Inter", ui-sans-serif...` hardcoded, no display/mono, no `@theme inline`
- All headings and body shared same font — no typographic hierarchy, no mono for code tags
- `layout.tsx` only loaded Inter (no swap/preload explicit, no JetBrains/Space Grotesk)

**After:**
- 3-font system with semantic roles, explicit `display: swap`, `preload: true`, `variable`
- Tailwind utilities `font-display`/`font-mono` available app-wide, Astryx `--font-heading` alias kept
- Headings are geometric/tech-forward (Space Grotesk), tech tags/numbers are monospaced (JetBrains), body stays highly legible (Inter)
- CLS-safe via Next fallback metrics + `font-synthesis: none`; palette untouched
- No bundle bloat: `First Load JS 103 kB` (unchanged), static build `○ / 127 B`

## Astryx Compatibility

ui-kit `globals.css` maps `--font-sans: var(--astryx-font-family-body)` etc. Seridian does not install `@astryxdesign` at runtime but mirrors the token contract: `--font-sans` (body), `--font-heading` (alias to `--font-display`), `--font-mono`. Importing `@bytecats/ui-kit/styles.css` alongside Seridian globals will not clash — consuming apps can set `data-ui-theme="neutral"|"stone"` if needed; Seridian's font variables are namespaced but share the token shape.
